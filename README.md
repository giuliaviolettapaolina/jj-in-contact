# JJ – In contact met

Klikbaar prototype van de flow "Nieuwsvraag, tip of weerfoto?" voor NOS Jeugdjournaal, gebouwd vanuit het Figma-prototype.

**Bekijk het prototype:** https://giuliaviolettapaolina.github.io/jj-in-contact/

## Flow
1. Homepage → knop **Deel het met ons hier** opent het keuzevenster.
2. **Ik heb een vraag over het nieuws** → artikelpagina "Welke vraag heb jij over het nieuws?" met het reactiepaneel direct open.
3. **Ik heb een nieuwstip** / **Ik heb een weerfoto** → opent je mailprogramma met een vooringevulde mail.

## Lokaal bekijken
Open `index.html` in een browser.

Afbeeldingen en artikelen worden geladen van jeugdjournaal.nl (stand 12 november 2026).
